# manufacturing-lexical-boundary

Mandatory frontier before surface manufacturing. A lexical gate between
pressure and prose: nothing crosses into the scene carrying doctrine.

## When to use

Before generating any surface prose from a mechanism, spec, or pressure map.
Especially when the source material is theoretical (spines, engines, doctrines).

## The boundary

Run this check on every scene draft before it ships:

1. **No doctrine vocabulary in scene.** Words like provenance, route,
   contradiction, carrier, selection, kernel, runtime, substrate stay in the
   workshop. The scene may *run* them; it may not *say* them.
2. **No borrowed jargon.** If a term arrived from another domain (physics,
   systems, military), it crosses only if the scene re-earns it.
3. **No register contamination.** RAW stays RAW; Forensic stays Forensic.
   A technical term inside a fable is a leak, not a bridge.
4. **The brilliance test.** "Si aparece una frase brillante pero no carga
   acción, debe cortarse o enterrarse." A beautiful sentence that carries no
   pressure is contraband — cut it or bury it inside an object.

## Pass / fail

- **Pass:** a reader who knows nothing of the system feels the pressure anyway.
- **Fail:** the scene explains the mechanism, names the tool, or teaches the
  lesson. Send it back through the boundary.
