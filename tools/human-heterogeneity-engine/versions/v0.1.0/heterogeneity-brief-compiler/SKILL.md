# Heterogeneity Brief Compiler

Internal factor model must not become visible checklist prose.

Pass only:
- local desires
- relationships
- practical competencies
- language conditions
- authority relations
- social stakes
- history necessary for scene
- domain-specific constraints

Do not tell the writer:
“show cultural nuance,”
“avoid stereotype,”
“demonstrate age asymmetry,”
unless explicitly requested.

Do not force each factor to receive a scene.

The writer should receive people, not dimensions.

Use hidden evaluator for:
- stereotype bundle
- same-mind syndrome
- competence alignment
- domain collapse
- multilingual prestige bias
- blind attribution
