# Human Factor Model

Core question:

> Is this person being modeled as a human configuration, or as a correlated demographic bundle?

Represent separately:

- age / life stage
- language repertoire
- language-specific fluency
- language-specific emotionality
- cultural history
- migration history
- class / money position
- institutional power
- local social power
- technical competence
- practical competence
- emotional competence
- intercultural competence
- physical confidence / limitation
- education
- professional history
- family role
- status sensitivity
- conflict style
- politeness strategy
- authority response
- shame triggers
- obligation model
- risk tolerance
- memory habits
- temporal horizon
- current domain knowledge
- private desire
- blind spots

Do not infer one factor automatically from another.

Examples of forbidden automatic coupling:
multilingual → cosmopolitan → emotionally sophisticated
old → wise → patient → technophobic
teen → informal → impulsive → digitally competent
Icelandic → blunt
Indonesian → indirect
monolingual → culturally narrow

Correlations may exist in a specific person, but must be earned by history, not demographic shorthand.
