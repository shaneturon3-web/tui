# Adaptive Patch Grafter

## Mechanism

`SHARD + HOST SCENE`
→ `REGISTER ALIGNMENT`
→ `LOCAL EMBODIMENT`
→ `CAUSAL RESIDUE`
→ `CONTROLLED MISALIGNMENT`

## 1. Register Alignment

Match:

- sentence length;
- lexical density;
- point of view;
- sensory regime;
- technical sophistication;
- cultural assumptions.

The graft should not announce a different authorial mode.

## 2. Local Rationalization

Characters may possess mundane explanations.

They do not need to perceive the shard as ancient, secret, religious, or conspiratorial.

## 3. Causal Residue

The patch must change at least one:

- available action;
- interpretation;
- debt;
- delay;
- relationship;
- resource flow;
- future callback.

If nothing changes, it is decorative lore.

## 4. Controlled Misalignment

Preserve one small roughness:

- unexpected word;
- unexplained hesitation;
- unusable field;
- color in wrong context;
- procedure nobody owns;
- physical asymmetry.

## 5. Patch Test

Remove the graft.

If the host scene is identical in future consequence, either strengthen the causal residue or classify the shard as texture-only deliberately.

## Failure Mode

If the graft forces characters to stop and explain it, use the Obscure Lineage Guard.
