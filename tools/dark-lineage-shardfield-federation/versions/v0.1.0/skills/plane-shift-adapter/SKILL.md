# Plane Shift Adapter

Provenance: reconstructed from the installed `reshuffle-plane-shifting` / `shuffle-and-reshuffle` candidate skills. This bundled adapter is self-contained and does not claim to be the recovered original Abracadabra skill.

1. Freeze the current candidate and resolution.
2. State an observable reason for another pass.
3. Select a DIFFERENT plane: carrier, environment, order, relation, function, scale, observer, reader knowledge, or unit size.
4. State intended invariant and allowed mutations.
5. Reorganize under receiving-work pressure; do not import donor phrasing/sequence by default.
6. Compare causal function, receiver fit, autonomy, information route, donor resemblance, new assumptions, symmetry, and residue.
7. Keep both versions in the audit. Reject the new pass if it adds ornament, explanatory machinery, unsupported causality, or merely repeats the previous movement.
8. Stop when another pass no longer changes the work materially.
