# Obscure Lineage Guard

## Reglas de Opacidad Implacable

1. **Prohibición de Explicación Doctrinal (Hard Rule)**:
   - NUNCA escribir una escena donde dos personajes se sienten a explicar la 'Orden', el origen del símbolo o la historia del linaje.
   - La existencia del linaje debe balancearse en la frontera: `Recurrencia → Sospecha → Proveniencia Contradictoria → Recurrencia Mayor → Sin Adjudicación`.

2. **Dudas de Invariante (Invariant Doubt)**:
   - Introducir siempre una explicación alternativa plausible (coincidencia, evolución convergente, vicio de oficio) para que el lector no esté seguro de si el linaje es real o una invención del observador.

4. **Recurrence is not proof of lineage or shared Kultur.** Similar forms, habits or functions can arise through convergence. Continuity of practical pressure may outlast the original meaning, but does not by itself prove a shared origin, transmission path or continuing Kultur. If a carrier-to-carrier path is not established, keep convergence and coincidence available; do not adjudicate the lineage.

**Review 0.1.1 — 2026-11-02 15:16 EST (America/Toronto).** This clarifies the boundary already held by the recurrence / suspicion / contradictory provenance sequence. It does not resolve the genealogy, identify an origin, or relax the guard's opacity rule.

3. **Invarianza de Presión sin Significado**:
   - El significado original del hábito o palabra puede haberse perdido hace siglos, pero la **presión práctica sobre la decisión actual permanece intacta**.
