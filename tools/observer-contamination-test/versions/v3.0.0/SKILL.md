# Observer Contamination Test

## Mechanism

`RECURRENCE NOTICED`
→ `CATEGORY FORMED`
→ `CATEGORY CHANGES ATTENTION / COPYING / ARCHIVING`
→ `FUTURE OBSERVATIONS BECOME NON-INDEPENDENT`
→ `PATTERN APPEARS STRONGER`

## Trigger

Run whenever someone:

- names the pattern;
- publishes a study;
- creates a museum/archive;
- teaches recognition criteria;
- labels artifacts;
- builds a detector;
- forms a community around the hypothesis;
- suppresses the alleged lineage;
- markets or imitates its aesthetics.

## Contamination Channels

### Attention Bias
Observers begin noticing only matching cases.

### Archive Bias
Matching artifacts are preserved disproportionately.

### Copying
People intentionally reproduce the discovered style.

### Defensive Mutation
Groups alter behavior to avoid classification.

### Prestige Diffusion
The suspected lineage becomes fashionable.

### Opposition Diffusion
Enemies preserve the pattern by banning it.

### Detector Feedback
Automated systems trained on prior classifications amplify their own ontology.

## Required Distinction

For each post-publication recurrence ask:

`independent evidence?`
`influenced evidence?`
`unknown?`

## Strong Form

The investigation may create a historically real lineage that did not previously exist in that coherent form.

This does not make earlier evidence fake.

It changes the object.

## Negative Fixture

A recurrence documented before any plausible exposure remains independent of the later category, subject to ordinary provenance limits.

## Failure Mode

Do not use observer contamination as an all-purpose excuse to dismiss evidence.
