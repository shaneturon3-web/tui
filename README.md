# The Unfinished Inheritance

**Motto:** The Order Is Not the Origin.

Repositorio privado de manuscritos, obras independientes y herramientas literarias. Entrada: `MANIFEST.txt` y `PROJECT-CONTROL.txt`.

- Cada obra de serie tiene rama `books/<id>-<slug>` y sus archivos dentro de `books/<id>-<slug>/`.
- Las obras independientes comparten rama `independent`, en carpetas separadas.
- Cada herramienta tiene rama `tools/<slug>` y sus versiones bajo `tools/<slug>/versions/`.
- La rama principal mantiene índices, decisiones, control y registro. No presume que los manuscritos estén fusionados a `main`.
- Las mismas rutas relativas e identificadores se usan al copiar a Google Drive y bibliotecas; una copia no asciende a canon por sí misma.

La presencia de un manuscrito no certifica revisión editorial ni aprobación canónica.
